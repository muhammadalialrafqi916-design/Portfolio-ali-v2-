## Tentang Proyek

Ini adalah website portofolio pribadi yang saya buat untuk menghadirkan profil profesional saya dalam satu tempat. Di dalamnya, pengunjung dapat mengenal saya, melihat teknologi yang saya gunakan, menjelajahi proyek pilihan, dan menghubungi saya dengan mudah.

Dibangun dengan pendekatan modern, responsif, dan berfokus pada pengalaman pengguna—agar tampil nyaman di desktop maupun perangkat mobile.

> **Lihat versi live:** [muhammadalialrafqi916-design.github.io/Portfolio-ali-v2-/](https://muhammadalialrafqi916-design.github.io/Portfolio-ali-v2-/)

## Fitur

- Tampilan modern, minimalis, dan responsif
- Perkenalan singkat serta profil profesional
- Showcase proyek pilihan beserta tautan demo dan source code
- Bagian teknologi atau keahlian utama
- Form/tautan kontak dan sosial media
- Animasi halus untuk pengalaman yang lebih hidup
- Optimasi tampilan untuk mobile, tablet, dan desktop
